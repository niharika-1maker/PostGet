# Contributing to AI Content OS

## Before starting
- Read `AGENTS.md` and relevant documents in `docs/`.
- Check existing issues/tasks and current implementation.
- Confirm scope and acceptance criteria.

## Branch and commit guidance
- Use focused branches and small commits.
- Keep changes scoped to one coherent task.
- Use descriptive commit messages.
- Do not commit secrets, generated media, local databases or temporary files.

## Pull requests
Every PR should explain:
- Problem and intended behavior.
- Implementation summary.
- Screenshots or recordings for UI changes.
- Database/API changes.
- Security and cost implications.
- Tests run and exact results.
- Known limitations and follow-up work.

## Definition of done
- Acceptance criteria are met.
- Tests and quality checks are run.
- Documentation is updated.
- No secrets or unrelated changes are included.
- Failure states and authorization are handled.
